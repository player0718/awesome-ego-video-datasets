## Coverage and selection

Three date-filtered arXiv API queries returned 138, 167, and 43 records: **281 unique papers** after deduplication. Every returned title was screened; potentially relevant papers were reviewed through abstracts and author/project resources. Each query requested 250 results and returned fewer than that limit, so no result page was omitted. **32 papers from that candidate set are linked in the updated README.**

Hugging Face name searches (`egocentric`, `ego`, `wearable`, `first-person`) and the `egocentric` tag yielded **221 recently modified candidate repositories** after deduplication. The broad `ego` query was expanded to 500 records, reaching back to May; name hits, conversions, private working copies, and unrelated sensor data were screened separately. **51 dataset-card fetches** were attempted for shortlisted or source-linked candidates. Two date-filtered GitHub repository searches returned **15 unique repositories**, all within the first result page. Official project pages, paper-linked repositories, workshop pages, and publisher release notes supplemented these searches.

The [screening inventory](2026-09-26-screening.json) records dates, links, screening stage, decisions, and unresolved metadata. README remains the maintained resource catalogue; this report is a dated research snapshot.

Inclusion prioritizes identifiable first-person video corpora, new annotations or benchmark protocols, relevant synthetic/robot first-person evaluations, and usable collection tools. Image-only adjacent benchmarks are labeled explicitly. Generic driving methods, wearable physiological signals, re-uploads, and training caches are separated from new egocentric resources.

## Verification and limits

New primary entries were checked for one overview row and one full entry, consistent names/years, appropriate topic placement, and source links. Markdown table widths and whitespace were checked. All 66 newly introduced primary links returned HTTP 200 when fetched without logging in or downloading video corpora. An HTTP success confirms a reachable page, not unrestricted data access or a completed dataset release.

This is a systematic search of the stated public sources and time window. It cannot prove the absence of unindexed, renamed, private, or undocumented releases. Creation and modification timestamps are preserved as metadata rather than treated as scientific release claims. Access-restricted and poorly documented candidates remain explicitly unresolved.
